## 1. Root cause detail

File: `internal/domain/scoring.go`, line 12:
```go
type EvidenceLevel int
```

With constants:
```go
const (
    EvidenceUnknown EvidenceLevel = iota      // 0
    EvidenceUnverified                        // 1
    EvidenceConfirmed                         // 2
)
```

Go's default JSON encoder serializes `EvidenceLevel` as a number (0/1/2), not as a string. The Hugo template `web/layouts/partials/home-story.html` uses `$story.evidenceLevel` directly:

```go-html-template
<span class="story-evidence story-evidence-{{ $story.evidenceLevel }}">
```

This produces `class="story-evidence story-evidence-2"` instead of `class="story-evidence story-evidence-confirmed"`.

## 2. Implementation steps

### Step 1: Add MarshalJSON and UnmarshalJSON to EvidenceLevel

**File:** `internal/domain/scoring.go`

Add these methods after the existing `String()` method:

```go
// MarshalJSON implements json.Marshaler for EvidenceLevel,
// outputting a human-readable string instead of an integer.
func (e EvidenceLevel) MarshalJSON() ([]byte, error) {
    return json.Marshal(e.String())
}

// UnmarshalJSON implements json.Unmarshaler for EvidenceLevel,
// parsing a JSON string back to the correct const value.
func (e *EvidenceLevel) UnmarshalJSON(data []byte) error {
    var s string
    if err := json.Unmarshal(data, &s); err != nil {
        return err
    }
    switch s {
    case "confirmed":
        *e = EvidenceConfirmed
    case "unverified":
        *e = EvidenceUnverified
    default:
        *e = EvidenceUnknown
    }
    return nil
}
```

Also add the `encoding/json` import if not already present.

### Step 2: Add unit tests for EvidenceLevel JSON round-trip

**File:** `internal/domain/scoring_test.go`

Add a new test function:

```go
func TestEvidenceLevel_JSONRoundTrip(t *testing.T) {
    cases := []struct {
        level    EvidenceLevel
        expected string
    }{
        {EvidenceUnknown, "unknown"},
        {EvidenceUnverified, "unverified"},
        {EvidenceConfirmed, "confirmed"},
    }

    for _, tc := range cases {
        t.Run(tc.expected, func(t *testing.T) {
            // Marshal to JSON
            data, err := json.Marshal(tc.level)
            if err != nil {
                t.Fatalf("Marshal: %v", err)
            }
            wantJSON := `"` + tc.expected + `"`
            if string(data) != wantJSON {
                t.Errorf("Marshal: got %s, want %s", data, wantJSON)
            }

            // Unmarshal back
            var decoded EvidenceLevel
            if err := json.Unmarshal(data, &decoded); err != nil {
                t.Fatalf("Unmarshal: %v", err)
            }
            if decoded != tc.level {
                t.Errorf("Unmarshal: got %v (%s), want %v (%s)",
                    decoded, decoded.String(), tc.level, tc.level.String())
            }
        })
    }
}
```

3. **time.Duration for duration_ms:** Left as-is for now. If the feeds page shows nanosecond values, fix as a follow-up. This does not block HS-015 or AC3 (status names work even if duration is numeric).
