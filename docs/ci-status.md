# CI Configuration for HuddleScope

## Status

- **Issue:** HS-002 - Add CI, testing, linting, and vulnerability scanning
- **Status:** Local lint/security blocked by Go version incompatibility

## Problem

The system uses Go 1.27.3 but tool binaries (`golangci-lint v2.15.0`, `gosec v2.29.0`, `govulncheck v1.9.0`) were compiled with Go 1.27.2. Go uses a minor-version-specific binary export data format. Binaries compiled with Go 1.27.2 cannot read the cache generated by Go 1.27.3.

## Evidence

```
$ go version
go version go1.27.3 darwin/arm64

$ golangci-lint --version
golangci-lint has version 2.15.0 built with go1.27.2
```

Error message:
```
could not import context (reading ...): internal error in importing "context" 
(cannot decode "context", export data version 5 is greater than maximum supported version 4)
```

## Local Workarounds

1. **Skip lint/security locally**: Use `make check-no-lint` and `make check-no-security` targets
2. **Compile tools with Go 1.27.3**: Rebuild tool binaries locally
3. **Use Go 1.27.2**: Install Go 1.27.2 manually (not available in Homebrew currently)

## CI Workflow Plan

The `.github/workflows/ci.yml` will:

1. Use GitHub-hosted runners with Go 1.27.3 installed
2. Install tool binaries using `go install` or pinned GitHub Actions
3. Run `go test -race`, `gofmt`, `go vet`, `golangci-lint`, `gosec`, `govulncheck`
4. Enforce 80% coverage on `internal/...` packages
5. Use least-privilege permissions, timeouts, and caching

## Notes

- Local `make lint` and `make security` fail due to Go version mismatch
- CI will use GitHub Actions runners with clean Go environment
- Tool binaries in CI will be compiled with the same Go version as the runner
