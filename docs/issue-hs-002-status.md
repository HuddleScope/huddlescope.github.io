### Blocking Issue

**Problem:** System uses Go 1.27.3 but tool binaries (`golangci-lint v2.15.0`, `gosec v2.29.0`, `govulncheck v1.9.0`) were compiled with Go 1.27.2. Go uses minor-version-specific binary export data format.

**Error:**
```
could not import context (reading ...): internal error in importing "context"
(cannot decode "context", export data version 5 is greater than maximum supported version 4)
```

**Root Cause:** The Go binary cache format changes between minor versions. Binaries compiled with Go 1.27.2 cannot read cache generated by Go 1.27.3.

**Workarounds:**
1. Use Go 1.27.2 (not available in Homebrew currently)
2. Rebuild tool binaries with Go 1.27.3
3. Skip lint/security locally and rely on CI

**CI Resolution:** The GitHub Actions workflow will use GitHub-hosted runners with Go 1.27.3 and install tools fresh each run, avoiding local cache issues.
